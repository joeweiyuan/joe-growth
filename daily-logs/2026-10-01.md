## 🔧 附：本次"文件没收到"的根因（已定位，非家主操作问题）

| 环节 | 实况 |
|------|------|
| 家主发送 | 飞书**富文本(post)消息**，附件在 post 的**顶层 `files` 字段** |
| 网关日志 | `Received raw message type=post` → `type=text … media=0`（**附件未被提取**） |
| 根因 | 飞书适配器解析 post 时只扫**正文 content 行**里的 `file_key`，**未处理顶层 `files` 数组** → 附件被丢弃 |
| 六六处置 | 用飞书 OpenAPI `im/v1/messages/{id}` 取回原始消息 → 命中 `files[0]` → 下载 resource → ✱9,914 字节 xlsx |

> 已沉淀可复用脚本：`scripts/fetch_feishu_attachment.py`（按 message_id 取回被适配器丢掉的附件）
