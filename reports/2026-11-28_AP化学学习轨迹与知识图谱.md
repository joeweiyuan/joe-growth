## 四、已讲知识点（逐条落细）

### 试听课（11/21）
1. **电子云（electron cloud）**：电子不是沿固定轨道运行，而是以概率分布存在
2. **海森堡不确定原理**：位置与动量不能同时精确确定
3. **orbital（轨道/轨函）≠ orbit（玻尔轨道）**
4. **电子排布（electron configuration）** 的书写
5. **能级交错（energy overlay）**：4s 与 3d 的能量次序
6. **能量最低原理**：电子先填低能轨道，填满再填下一个
7. **亚层（subshell）** 概念：s / p / d / f

### 第 1 课（11/28）
1. **电子排布 → 电子层数 → 半径** 的推理链
2. **等电子体（isoelectronic species）比较**：电子数相同 → **比质子数**，质子数越大半径越小
   - 典型组：Na⁺、Mg²⁺、F⁻、O²⁻、Ne
3. **元素分类**：金属 / 非金属 / 准金属（metals / nonmetals / metalloids）
4. **电离能（ionization energy）**：定义（气态原子失去一个电子所需能量）；同周期从左到右增大、同主族从上到下减小
5. **原子半径趋势**：同周期减小、同主族增大
6. 课堂练习：isoelectric species 中半径最小的是哪一个

**已建立的地基**：1.5（电子排布）与 1.7（周期性趋势）是一对强关联内容，老师连着讲是对的；等电子体比较已经讲到"比质子数"这个核心判据，方向正确。

**三个缺口**：
1. **1.6 PES 完全空白** —— 这是 AP 高频考点，也是"排布"的实验证据。趁 1.5 刚学完接上，认知成本最低。
2. **1.1 / 1.2 有题库但未见课堂记录** —— 需要确认是"布置自学"还是"跳过了"。摩尔计算是后面所有化学计量的地基，不能留空。
3. **1.3 / 1.4 / 1.8 未涉及** —— 属正常进度，但 1.3（实验式/分子式）是 MC 常客，别拖太后。

**建议的第 2 课顺序**：1.6 PES → 1.8 价电子与离子 → 回头补 1.1/1.2 计算题
理由：PES 直接复用刚学的排布知识；1.8 是 1.7 的趋势结论的应用；计算类（1.1/1.2）适合作为课后练习而非课堂主线。
