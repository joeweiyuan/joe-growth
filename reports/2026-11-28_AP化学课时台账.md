## 三、第 1 课内容（2026-11-28）

**主线：电子排布 → 层数 → 半径；等电子体的比较方法**

| 知识点 | 具体内容 |
|:--|:--|
| 电子排布 | 写出指定粒子（原子/离子）的电子排布式；由排布确定核外电子层数 |
| 层数与半径 | 电子层数越大 → 粒子半径越大（同主族方向的主要判据） |
| 等电子体 | 电子数相同的粒子（如 Na⁺ / Mg²⁺ / F⁻ / O²⁻ / Ne）→ **比较核电荷数（质子数）**：质子数越大，对电子吸引越强，半径越小 |
| 半径变化规律 | 同周期从左到右半径减小（核电荷增加、层数不变）；同主族从上到下半径增大（层数增加） |
| 元素分类 | 金属 / 非金属 / 准金属（metals / nonmetals / metalloids） |
| 电离能（IE） | 定义：气态原子失去一个电子所需能量；同周期从左到右增大、同主族从上到下减小 |
| 电负性 / 电子亲和能 | 电负性同周期增大、同主族减小；电子亲和能变化趋势及例外 |
| 例题类型 | ①写离子电子排布 ②等电子体半径排序 ③由排布反推粒子 ④Na 气态→离子的电子变化 ⑤isoelectric species 找半径最小 |
