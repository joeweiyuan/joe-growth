---

## 一、归档规则（每次研究必做）

1. **命名**：`YYYY-MM-DD_<主题>.md`（如 `2026-09-30_逐校官方核实.md`）
2. **必含四段**：① 研究问题 ② 数据来源（**逐条 URL/文件路径**）③ 结论 ④ 可复用维度（给 OfferPath 的接口）
3. **数据纪律**：每个数字标来源；无来源写「待核实」；估算值必须标 `estimated` + 置信度
4. **登记**：写入本目录后，同步更新 `_index.json`
5. **双副本**：`joe-growth/research/` 与 `joe-growth-tracker/research/` 保持一致

## 三、对 OfferPath 的接口（可复用维度）

| 维度 | 说明 | OfferPath 对应表/字段 |
|------|------|---------------------|
| 目标校要求 | 标化/DDL/补充文书/招募流程（带官方 URL） | `universities.admission_info` (jsonb) |
| 中国录取趋势 | 目标校中国学生录取规模与年份变化 | `admissions` |
| 生源高中 | 高中 → 录取去向（含本校口径） | `high_schools` / `admission_schools` |
| 评估输入档案 | GPA/托福四单项/雅思/SAT/ACT/AP/活动/目标专业 | `evaluations` |
| 标化口径映射 | 六分制 ↔ CEFR ↔ 120 制 | 新增建议字段 |
| 案例材料 | 履历/文书素材/成长叙事（可作 sample 数据） | 暂无对应表 |

## 四、⚠️ 数据真实性红线

- **只归档有来源的数据**；估算/推测必须显式标注
- 归档目录内的所有材料，OfferPath 引用时**必须保留来源与置信度字段**
- 禁止把「某校录取 N 人」这类数字去掉 confidence 后当成官方事实使用
