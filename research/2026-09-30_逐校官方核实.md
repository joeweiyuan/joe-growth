# 逐校官方核实（2026-09-30）

> 研究问题：目标校的**标化政策 / 申请轮次与截止 / 补充文书 / 赛艇招募**官方要求是什么？
> 方法：3 个子 Agent 并行核实（只读官网），另派独立 Checker 抽查复核
> 结果：**6 校完成**（MIT·Stanford·Harvard·Yale·Princeton·Columbia）｜ 4 校重跑中（Dartmouth·Brown·Cornell·Penn）
> 台账：`admissions/09-官方核实台账.md` ｜ 原始 JSON：`research/raw/`

## 关键结论（速览）

| 学校 | 最关键一条 |
|------|-----------|
| MIT | 标化**必交**；EA 11/1 + RA 1/4；**TOEFL 90/建议 100**（2026-01 起新制 5/5.5） |
| Stanford | 标化**必交**（2026 秋起恢复）；REA 11/1 + RD 1/5；**本科不要求英语考试** |
| Harvard | 标化必交；REA 11/1 + RD 1/1；赛艇**轻量级有公开 erg 标准（2K sub 6:30）** |
| Yale | 标化必交 + 英语测试（TOEFL 100+/新制 5+）；SCEA 11/1 + RD 1/2；招募流程官网未公布 |
| Princeton | 26-27 test-optional，**27-28 起恢复**标化；SCEA 11/1 + RD 1/1；**唯一公布完整招募流程+4教练邮箱** |
| Columbia | 26-27 test-optional，27-28 恢复；ED 11/1（绑定）+ RD 1/1；招募页缺失 |

## 可复用维度（给 OfferPath）

| 维度 | 去向 |
|------|------|
| 标化政策（含六分制新制口径） | `universities.admission_info` |
| 轮次与截止日（含申请季年份） | `admissions` / 新建议字段 `deadlines` |
