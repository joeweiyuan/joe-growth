## 一、Unit 1 考点清单（1.1–1.8）

| 小节 | 核心技能 | 常见题型 | 高频错点 |
|:--|:--|:--|:--|
| 1.1 Moles & Molar Mass | 质量↔物质的量↔粒子数；摩尔分数；密度换算 | 计算型 MCQ | 忘记乘 Avogadro 数；摩尔分数用质量比；单位不统一 |
| 1.2 Mass Spectra | 读质谱；同位素丰度；加权平均原子质量 | 图像型 MCQ | 用简单平均而非加权；把 m/z 当质量数 |
| 1.3 Elemental Composition | 质量百分比→实验式→分子式 | 计算 MCQ / 短答 | 实验式与分子式混淆；未用摩尔质量验证 |
| 1.4 Composition of Mixtures | 混合物定量、分离方法 | 情境 MCQ | 均相/非均相判断错 |
| 1.5 Atomic Structure & Electron Config | 量子数含义；能级交错；构造原理/泡利/洪特；基态 vs 激发态；离子排布；未成对电子 | MCQ + 解释类 FRQ | 4s/3d 顺序；过渡金属失电子先失 4s；未成对电子数错 |
| 1.6 Photoelectron Spectroscopy | PES 峰位=结合能、峰高=电子数；由谱反推排布 | 图像 MCQ / 解释 FRQ | 峰高与结合能混淆；未按亚层数峰 |
| 1.7 Periodic Trends | 半径、电离能、电负性；等电子体；有效核电荷与屏蔽 | MCQ + 解释 FRQ | 等电子体比电子数；忽略屏蔽；第二电离能突跃解释 |
| 1.8 Valence Electrons & Ionic Compounds | 价电子；离子电荷预测；离子化合物组成 | MCQ | 过渡金属价电子；主族电荷规律 |

## 二、出题规则

### 题型配比（一份 20 题的标准卷）
- MCQ 14 题（4 选项 A–D，与原题一致）
- 短答/计算 4 题（写出过程）
- 解释类 FRQ 2 题（“Explain why…” 型）

### 题目质量硬要求
1. **单一考点**为主：每题明确对应一个小节，避免跨节混考（除非做综合卷）
2. **干扰项要有诊断价值**：错选项对应典型错误（如 1.5 题把 4s/3d 顺序设成干扰项）
3. **数据自洽**：涉及数值的题必须能用给定数据算通，禁止“看起来合理”
4. **不用未定义符号**：与 AP 官方符号一致（如 molar mass、ionization energy）

### 来源标注（强制）
- 直接取自已归档官方题库 → `【官方题库】小节 1.x，第 n 题`
- 我自编 → `【非真题·按官方蓝本命制】`
- **绝不把自编题标成真题**

## 三、批改规则（FRQ）

### 采分结构
AP 化学 FRQ 基本是 **1 分 = 1 条正确陈述**。批改时：
1. 先把标准答案拆成“可独立判分的点”（claim / evidence / reasoning）
2. 逐点打 ✅/❌，给总分
3. 对每个 ❌ 写：**错在哪 → 为什么会错 → 正确表述**

### 常见给分口径
| 情形 | 给分 |
|:--|:--|
| 结论对、理由缺 | 通常得 0（解释题要求理由） |
| 结论对、理由部分对 | 按点给 |
| 计算题只有答案无过程 | 视题目要求，通常扣过程分 |
| 单位错/缺 | 按点扣，不整题判错 |
| 有效数字 | AP 一般不因有效数字扣分，但明显荒谬需指出 |

### 输出格式
```
总分：x / y
逐题：
  Q1 ✅ 2/2 — 结论+理由均到位
  Q2 ⚠️ 1/2 — 结论对；漏了“屏蔽效应”这一步
       正确表述：……
错因归类：概念(1) / 计算(0) / 表述(1)
下一步：重做 1.7 等电子体 3 题
```

## 四、禁止事项
1. ❌ 声称自己给的是 College Board 官方答案（官方题库不带答案）
2. ❌ 用“感觉”给分，必须有 rubric 点
3. ❌ 编造题目数据导致算不通
4. ❌ 把 BC 内容（如热力学细节）混入 AB 范围题
