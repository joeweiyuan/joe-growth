# 软实力分级标准（B3）v1

> 用途：把「竞赛 / 科研 / 领导力 / 特长」从主观描述变成**可分档、可横向比较**的等级。
> ⚠️ 本表是**六六内部标准**（参考主流美本/英本申请语境的常见分层），**不是任何官方评级**。对外使用必须注明。

---

## 一、等级定义（五档）

| 等级 | 分值 | 含义 | 在申请中的位置 |
|:--:|:--:|:--|:--|
| **S** | 100 | 国际级/国家级顶尖，稀缺 | 能单独撑起一个申请故事 |
| **A** | 80 | 国家级奖项 / 国际赛事晋级 / 有同行评审产出 | 强凭证，可作主活动 |
| **B** | 60 | 省级一等奖 / 校级核心角色 / 长期深度投入 | 有力支撑 |
| **C** | 40 | 市级/校际 / 社团成员 / 短期参与 | 填充，不构成区分度 |
| **D** | 20 | 参与记录（无结果） | 基本不加分 |

**时长系数**：`0.85 + 0.10 × 年数`（封顶 1.25）
→ 同样 A 级，坚持 4 年比 1 年高 25%。**这是在奖励持续性，不是奖励堆数量。**

## 三、科研类锚点

| 等级 | 锚点 |
|:--:|:--|
| S | 同行评审期刊一作 / 国际会议口头报告 |
| A | 丘成桐/ISEF 级别入围 + 完整论文；或实验室项目有可验证产出 |
| B | 校级科研项目 + 完整论文/报告（有导师） |
| C | 课程内研究性学习 |
| D | 仅参与，无产出 |

**三条红线**：① 买来的论文不算；② 挂名不算；③ 无法解释方法的不算。

| 等级 | 锚点 |
|:--:|:--|

## 六、使用规则

1. **一条经历只定一个档**，不许"综合评估"成模糊区间。
2. **必须填 evidence**（赛事全名 + 年份 + 奖项等级 + 可验证链接/证书），空 evidence 一律降一档。
3. **同级别堆 5 条 ≠ 升档**：广度只加 2 分/条，封顶 8 分（防止刷活动）。
4. 每年复核一次：赛事含金量会变（新赛事贬值是常态）。

## 七、与评分引擎的接口

```json
{
  "depth": [
    {"name": "iENA 纽伦堡国际发明展", "level": "A", "years": 1,
     "evidence": "2023 一等奖 / 证书编号 XXX"}
  ],
  "leadership": [
    {"role": "赛艇校队队长", "level": "B", "years": 2, "impact": "带队 12 人"}
  ],
  "talent": [
    {"domain": "rowing", "level": "B", "years": 4, "evidence": "2k 7:24.1 (2026-07)"}
  ]
}
```
引擎按 `等级分 × 时长系数` 计算，取最强项 + 广度加分。
