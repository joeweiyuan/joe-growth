## 4. 三个关键设计（决定产品上限）

### 4.1 评估体系：三层，可解释
```
原始数据（成绩/分数/活动）
   → 标准化（跨体系换算：AP/IB/A-Level/普高 → 统一 0-100 量表）
   → 维度分（学术 / 语言 / 深度 / 领导力 / 特长）
   → 综合分（加权 + 目标国家差异系数）
```
**必须可解释**：家长点开每一项能看到“为什么是这个分、差什么”。
**必须可追踪**：同一学生 6 个月后的增值曲线 → 这才是续费理由。

### 4.2 榜单口径：四维锁定
年份 × 地理范围 × 指标（offer/入读/录取率）× 大学范围。
> 同一份数据换个口径结论可能相反 → 产品里口径必须写进标题。

### 4.3 选校匹配：概率而非承诺
输出 `冲刺 20% / 匹配 45% / 保底 80%` 这样的**区间**，并注明“基于历史数据，非承诺”。
合规上必须这样写，否则就是“保录”话术。

## 6. 待家主拍板

1. **产品形态**：卖给机构的 SaaS（顾问用）／卖给家长的直客工具／两者都做？
2. **评估分**：先用行业经验权重（快），还是先做数据回归（慢但准）？
3. **数据边界**：录取数据只做公开信息聚合，还是要签学校/机构合作拿一手数据？
4. **首发市场**：上海（有本地校数据优势）还是全国？
5. **合规主体**：用现有公司主体，还是新设（涉及未成年人数据）？
